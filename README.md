🧠 General Knowledge Trivia

Welcome to General Knowledge Trivia! Test your knowledge in a dynamic 5-question challenge that scales in difficulty as you progress through the game.

🎮 Game Features

Progressive Difficulty Challenge: Face a sequence of 5 questions designed to get progressively harder:

🟢 Very Easy

🟡 Easy

🟠 Medium

🔴 Hard

🟣 Very Hard

High Replayability: Every question is randomly selected from its respective difficulty pool, making every playthrough unique.

Intuitive UI: Clean and straightforward user interface built for instant engagement.

🎓 Project Context

This project was developed as part of a university English practice activity. It showcases game loop mechanics, random pool management, and UI logic built with Unity and C#.
